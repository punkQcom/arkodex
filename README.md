# arkodex

> 👋 **New here?** Open this folder in Claude Code and type **`/welcome`**.

Games and experiments by arkodex. Live at **https://arkodex.punkq.com**.

## Run it on your computer

```
npm install
npm run dev
```

Then open http://localhost:5173. The page reloads by itself when you save a file.

## Change things

| What | Where |
|---|---|
| Name, intro text, footer links | `src/site.js` |
| Project cards | `src/projects.js` |
| Images | `public/images/` |
| Colours and layout | `src/style.css` |

## Publish

Push to `main`. GitHub builds the site and puts it online in about a minute.
You can follow it in the repo's **Actions** tab.
